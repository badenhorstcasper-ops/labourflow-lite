# Refresh the public homepage around CARA

## What is happening now

The public homepage uses a separate, older dark-blue design, so the recent light navy, teal and green app colours do not affect it. Its main product picture is also hidden on phones, which removes an important visual signal for mobile visitors.

## Recommended design

Make CARA the recognisable face of the product in the first screen:

- Change the homepage to the same light, premium palette as the app: pale blue-grey background, white surfaces, navy headings, teal CARA highlights and green only for positive reassurance.
- Place the supplied CARA portrait beside “Have a labour problem? Ask CARA.” with a small “Online · South African labour guidance” label.
- Keep CARA visible on phones, positioned between the opening message and the main action buttons rather than hiding the visual.
- Present the free question as the main action, with the seven-day trial as the next action. Keep sign-in easy to find.
- Restyle the remaining homepage sections, price options and footer consistently so the page does not switch back to the old dark appearance further down.
- Preserve the existing restaurant and supermarket versions, wording changes, share links, payment links and all current behaviour.

## Checks

- Check the homepage at phone and desktop sizes, including the opening section, CARA image, buttons, pricing and footer.
- Check the restaurant and supermarket homepage versions still show their correct content and links.
- Confirm text contrast, image clarity, touch-button size and that no content overlaps.

## Technical details

- Update the public homepage’s own colour rules rather than relying on the app’s colour rules, because these are currently separate.
- Reuse the existing CARA portrait asset already used inside the app.
- Make presentation-only changes; no changes to sign-up, trial, payments, CARA answers or account access.
